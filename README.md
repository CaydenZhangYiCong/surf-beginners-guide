# Surf Basics

A beginner-friendly surfing website with separate pages for learning the essentials.

## Run locally

Open `index.html` in a browser, or serve the folder with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Pages

- `index.html` — homepage
- `guide.html` — beginner surfing guide
- `gear.html` — surf gear essentials
- `safety.html` — surf safety and etiquette
- `glossary.html` — common surf terms
- `styles.css` — styling
- `script.js` — mobile menu and small interactions
